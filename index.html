04 Projects

Selected engineering work

AI Virtual Try-On for Fashion E-Commerce

Cygnowear Ltd · Production

Diffusion-based virtual try-on pipeline for a denim e-commerce platform, built from scratch with custom quantisation — no third-party quantisation library.

  • Cut peak inference VRAM by 42.9% (16.28 GB → 9.30 GB) with custom, from-scratch INT8 and INT4 weight quantisation.
  • Benchmarked five configurations end-to-end (VRAM, latency, colour accuracy); traced colour drift in attention slicing and xFormers+upcast to float16 operation-order non-associativity and a CUDA-kernel boundary issue.
  • Halved the minimum production GPU tier (24 GB → 12 GB) and cloud cost (~$1.00/hr A10G → ~$0.50/hr T4) by shipping INT8 as default, validated across 13 catalogue products.
  • Designed the production architecture (FastAPI + Celery/Redis + Docker, GPU worker concurrency=1) and a batch-testing engine that cut redundant model reloads from 52 to 4.

AI Based E-Commerce Platform

Full-stack · Machine-learning driven recommendations

A full-stack e-commerce platform with a trained recommendation engine serving real-time product suggestions to the frontend.

  • Built the full stack: ASP.NET Core, Entity Framework & Identity, PostgreSQL, React + TypeScript + Vite, and Flask/Python for ML services.
  • Trained and evaluated Random Forest, KNN, SVM, and K-Means on transactional data; selected Random Forest on accuracy, precision, recall, F1-score, and confusion matrices.
